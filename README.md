# Sales Performance Dashboard

## 📊 Project Overview

This project analyzes retail sales data using SQL and Microsoft Power BI to understand sales performance, profitability, product performance, and regional trends.

## 🎯 Objectives

- Analyze overall sales and profit performance
- Compare performance across regions
- Identify monthly sales trends
- Analyze product and category performance
- Create interactive business dashboards

## 🛠️ Tools & Technologies

- SQL
- Microsoft Power BI
- Microsoft Excel

## 📁 Project Files

- `Retail sales.pbix` — Power BI dashboard
- `Retail-Supply-dataset (1).xlsx` — Dataset used for analysis
- `sales_analysis.sql` — SQL queries used for data analysis

## 🔍 Key Analysis

The project includes analysis of:

- Total Sales
- Total Profit
- Orders
- Regional Performance
- Monthly Sales Trends
- Product Performance
- Category Performance

## 📈 Dashboard

The Power BI dashboard provides interactive visuals and filters to explore sales performance and business insights.
